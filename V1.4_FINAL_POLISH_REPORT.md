## 5. Backend & RAG Hardening Details

- **Safe CrossEncoder Loading:** Configured with `model_kwargs={"local_files_only": True}` with automatic fallback to standard loading and lexical heuristics if offline.
- **SSE Stream Cancellation Protection:** Active streams that disconnect before token completion are pruned from the query cache to prevent caching partial answers.
- **Gemini Model Fallback Prioritization:** Primary model updated to `gemini-3.6-flash` with graceful fallback chain (`gemini-3.5-flash-lite`, `gemini-3.5-flash`, `gemini-3-flash-preview`, `gemini-3.1-flash-lite`).
- **Prompt Injection Defense:** Multi-layered regex and heuristic filters sanitize adversarial vectors in both native and OCR-derived text before LLM context framing.
