## 3. Modular Target Layout

```
routers/
    __init__.py
    system_routes.py     # Root, health check, diagnostics, packaging (5 routes)
    auth_routes.py       # Register, login, OTP, password reset (6 routes)
    document_routes.py   # Upload, summary, get/delete/download docs (5 routes)
    conversation_routes.py # Conversation CRUD (5 routes)
    chat_routes.py       # Cloud/local chat, SSE streaming, warm-up (5 routes)
    rag_routes.py        # RAG evaluation endpoints (2 routes)
    analytics_routes.py  # Overview, latency, RAG distribution, model stats (4 routes)
    feedback_routes.py   # Submit feedback, get conversation feedback (2 routes)
    cache_routes.py      # Clear response cache (1 route)

schemas/
    __init__.py
    auth_schemas.py      # Register, Login, OTP, Password Reset models
    chat_schemas.py      # ChatRequest, Conversation models, FeedbackRequest

dependencies/
    __init__.py
    auth_deps.py         # get_current_user, login rate limiting helpers

main.py                  # Lightweight application entrypoint, CORS, global exception handlers, APIRouter inclusion.
```
