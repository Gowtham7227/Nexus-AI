## 4. Security & Tenant Boundary Verification

- **Authentication Enforcement:** Every protected route strictly includes `Depends(get_current_user)`.
- **Pre-Retrieval Authorization:** Document ownership validation (`validate_user_documents`, `document_belongs_to_user`) is executed **before** any vector search, cache lookup, or document reading.
- **Cache Isolation:** User ID is incorporated directly into the cryptographic cache key (`compute_cache_key`). Cross-user response retrieval is structurally impossible.
- **Path Traversal Shield:** Document filenames are sanitized via `validate_upload_filename` and path-traversal tested (`get_safe_document_path`).
- **Prompt Injection Defense:** Injected prompts in documents or queries are quarantined and safely treated as data.
