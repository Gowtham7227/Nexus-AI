## 🌟 Overview

NexusAI v1.4.0 introduces a dedicated research layer focused on multi-hop reasoning, evidence verification, conflict detection, and tabular data extraction, built directly upon the hardened modular foundation of v1.3.0.

All 35 API routes from previous versions remain fully preserved and backward-compatible.

---

## 🔬 New Capabilities & Improvements

### 1. Bounded Multi-Hop & Iterative Retrieval
- **Sequential Query Decomposition:** Automatically breaks complex multi-entity, temporal, and comparative questions into sequential sub-queries.
- **Cross-Hop Entity Bridging:** Intermediate entity names and context from earlier hops are dynamically injected into subsequent retrieval passes.
- **Bounding & Early Stopping:** Iterations are bounded (maximum 3 hops) and stop automatically when retrieved evidence achieves sufficiency.

### 2. Evidence Sufficiency Verification
- **Aspect-Level Coverage Evaluation:** Computes token and entity coverage ratios against query requirements.
- **Missing Claim Identification:** Flags ungrounded sub-claims prior to final generation.
- **Conservative Fallback:** Emits calibrated fallback responses when evidence coverage falls below minimum threshold (< 0.60).

### 3. Cross-Document Conflict Detection
- **Factual & Numerical Discrepancy Parsing:** Extracts numeric quantities, dates, percentages, and entity assertions across multiple ingested documents.
- **Contradiction Flagging:** Flags conflicting assertions across distinct documents and appends discrepancy warnings to response metadata.
- **Confidence Calibration:** Automatically adjusts answer confidence when unresolved source discrepancies are detected.

### 4. Table-Aware Structural Extraction
- **Grid Schema Parsing:** Parses structured tabular regions in PDF and text documents into formatted Markdown and CSV representations.
- **Preserved Header Context:** Preserves column headers and spatial page coordinates during chunking to maintain numerical association fidelity.

### 5. Backend & Pipeline Hardening
- **Local CrossEncoder Loading:** Configured with `model_kwargs={"local_files_only": True}` with automatic fallback to standard loading and lexical heuristics if offline.
- **SSE Stream Invalidation Protection:** Disconnected or aborted client streams are safely pruned from the query cache to eliminate partial answer caching.
- **Gemini Fallback Hierarchy:** Primary model configured to `gemini-3.6-flash` with graceful fallback chain (`gemini-3.5-flash-lite`, `gemini-3.5-flash`, `gemini-3-flash-preview`, `gemini-3.1-flash-lite`).

### 6. Frontend Enhancements
- **Research Metadata Badges:** The chat interface displays visual indicators for multi-hop hops executed, evidence sufficiency status, cross-document conflict alerts, and table-aware extractions.
- **Version Alignment:** `frontend/package.json` updated to `1.4.0`.

## 🔒 Security & Privacy Verification

- **Multi-Tenant User Isolation:** Verified on SQL and vector database queries.
- **Authentication:** JWT `alg:none`, tampered signature, and expired tokens strictly rejected (HTTP 401).
- **Ingestion Protection:** MIME validation, path traversal defense, and 100 MB upload limits enforced.
- **Output Privacy:** Real-time regex sanitization for API keys, SSNs, credit cards, and sensitive tokens.
