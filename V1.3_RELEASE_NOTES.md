## Overview

NexusAI **v1.3.0** delivers a major milestone in architectural maintainability, structural modularization, and production-grade runtime fault tolerance. This release transitions the backend from a monolithic 3,040-line `main.py` into a cleanly decoupled, layered architecture while preserving 100% functional and behavioral equivalence across all 35 API routes, core RAG retrieval algorithms, security policies, telemetry, and caching mechanics.

---

## Major Changes & Enhancements

### 1. Phase 1 — Production Runtime Hardening
- **SQLite Concurrency Resilience**: Implemented dynamic WAL configuration, `busy_timeout=60000ms`, and exponential backoff write retries. Handles high-concurrency bursts (verified across 10, 25, 50, and 75 concurrent write threads with 0 database lock errors).
- **ChromaDB Self-Healing**: Added automatic self-healing recovery and fallback vector store re-initialization to gracefully handle transient SQLite index locks or corrupt Chroma vector store segments.
- **Ollama Daemon Failure Isolation**: Integrated graceful circuit breaking and fallback degradation when local Ollama models are unreachable or fail mid-execution, preventing server unhandled exceptions.
- **Concurrent SSE Disconnect Handling**: Implemented non-blocking cooperative client disconnect polling (`request.is_disconnected()`) in streaming endpoints (`/chat/stream`, `/chat/general/stream`) to immediately abort orphaned background inference loops upon client disconnect.
- **Mid-Stream JWT Expiration Protection**: Added per-chunk token claim re-verification to prevent unauthorized continuation of streaming responses after token invalidation or expiration.

### 2. Phase 2 — Backend Architecture Modularization
The monolithic `main.py` was refactored into a layered architecture:
- **`main.py`**: Scaled down from **3,040 lines to 101 lines** (96.7% line count reduction), now acting strictly as an application orchestrator, lifespan manager, and APIRouter aggregator.
- **`schemas/`**: Dedicated Pydantic request and response schemas (`auth_schemas.py`, `chat_schemas.py`).
- **`dependencies/`**: Clean FastAPI dependency injection modules (`auth_deps.py`) for reusable session authentication and database scoping.
- **`services/`**: Business logic encapsulation (`document_service.py` for extraction/indexing/summaries, `chat_service.py` for RAG pipelines, streaming generators, and fallback dispatch).
- **`routers/`**: 9 domain-focused APIRouter modules registering exactly 35 endpoints:
  - `system_routes.py` (5 routes)
  - `auth_routes.py` (6 routes)
  - `document_routes.py` (5 routes)
  - `conversation_routes.py` (5 routes)
  - `chat_routes.py` (5 routes)
  - `rag_routes.py` (2 routes)
  - `analytics_routes.py` (4 routes)
  - `feedback_routes.py` (2 routes)
  - `cache_routes.py` (1 route)

### 3. Preserved Capabilities & Functional Parity
- **Full API Route Parity**: Exactly 35/35 endpoints preserved with identical HTTP verbs, status codes, query/body contracts, and error semantics.
- **Advanced RAG Core**: Multi-document retrieval, BM25 lexical indexing, dynamic hybrid score fusion, and XML grounding containment unchanged.
- **Tesseract OCR Pipeline**: Native PDF quality analysis and automatic OCR fallback preserved.
- **Transformer Cross-Encoder**: Local cross-encoder neural reranker (`cross-encoder/ms-marco-MiniLM-L-6-v2`) preserved with singleton thread safety.
- **Adaptive RAG Optimizer**: Sub-millisecond intent classification, dynamic retrieval strategy selection, and bounded query expansion preserved.
- **Response Caching**: Multi-tenant SHA256 document-fingerprinted response cache preserved with strict pre-cache tenant authorization.
- **Observability & Feedback**: End-to-end telemetry recording, latency timeseries, and user message feedback tracking preserved.
- **Security & Tenant Isolation**: JWT validation, SQL parameterization, path traversal shields, and PII redaction preserved.
